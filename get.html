How to install

Because the beta isn't in the Play Store yet, Android will ask you to allow the install once.

  1. On your phone, tap Download the APK above. Chrome may warn that the file could be harmful; tap Download anyway.
  2. When it finishes, tap Open in the notification, or find the file in the Files app under Downloads.
  3. If asked, tap Settings and turn on Allow from this source for Chrome (or your Files app), then go back.
  4. Tap Install. If Play Protect asks, choose Install anyway.
  5. Open Baruch Scribe and allow microphone access when you start your first session.

Updating? Install the new APK over the old one. Your settings and sessions stay put. iPhone is not available yet.
